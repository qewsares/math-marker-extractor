# Math Marker Extractor

Извлечение маркеров "тогда и только тогда" и "критерий" из PDF-статей с распознаванием формул.

## Установка и запуск

### Установка Miniconda

Скачать Miniconda с [официального сайта](https://www.anaconda.com/download/success).

```bash
# Перейдите в папку с проектом
cd путь_к_папке

# Создайте виртуальное окружение
conda create -n НАЗВАНИЕ_ОКРУЖЕНИЯ python=3.10 -y

# Активируйте его
conda activate НАЗВАНИЕ_ОКРУЖЕНИЯ

# Установите  зависимости
pip install pypdf PyMuPDF pillow pix2text natasha
# Запустите скрипт
python extractor.py
```
## Работа в Visual Studio Code
Откройте папку проекта в VS Code

Нажмите Ctrl + Shift + P → выбери Python: Select Interpreter

Выберите интерпретатор из созданного окружения (путь типа C:\Users\твое_имя\miniconda3\envs\НАЗВАНИЕ_ОКРУЖЕНИЯ\python.exe)

Откройте новый терминал (Ctrl + ~) — окружение активируется само

Запускайте скрипт кнопкой или командой python final.py

Если терминал не активирует окружение — напишите вручную: conda activate НАЗВАНИЕ_ОКРУЖЕНИЯ

**Самый надежный вариант работать напрямую из Anaconda Prompt!**

## Ограничения модели распознавания формул

В проекте используется библиотека Pix2Text для преобразования математических выражений в формат LaTeX. В процессе тестирования выявлены следующие ограничения:

### 1. Качество распознавания смешанного контента

При одновременном присутствии в выделенной области русского текста, английских символов и математических выражений модель демонстрирует нестабильные результаты. Возможно некорректное преобразование текста в LaTeX-разметку и появления лишних фрагментов
### 2. Зависимость от позиционирования маркера

Область страницы для распознавания формируется на основе координат найденного маркера. Если маркер расположен внутри предложения, выделенная область может захватывать фрагменты текста, не относящиеся к формуле, что снижает точность результата.

### 3. Ошибки при распознавании сложных выражений

Длинные формулы, а также конструкции, содержащие дроби, интегралы, суммы и матрицы, распознаются с ошибками или игнорируются моделью.

### 5. Извлечение авторов

Библиотека Natasha не гарантирует 100% точность. Из 40 обработанных PDF-файлов авторы не были найдены в 4 случаях из-за нестандартного оформления первой страницы (например, расположение авторов после аннотации или отсутствие инициалов). В остальных 36 файлах извлечение выполнено корректно.
